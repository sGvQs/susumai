Self-hosted LLM gateway

自分の Mac に、自分だけの LLM を持つ。

Ollama を動かせるマシンが1台あれば、GitHub アカウントでログインするだけで、どこからでも自分の LLM に話しかけられる。サーバー会社もアカウント登録も要らない。susumai はそのための zero-dep CLI と、経路を守る小さなゲートウェイ。

  • zero-dep CLI
  • GitHub Device Flow
  • トークン自動更新
  • 自分のドメインで固定トンネル
  • launchd 常駐
